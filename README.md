# Python Learning Labs

A collection of Python labs, workshops and certification projects completed as part of my ongoing **freeCodeCamp** training.

This repository documents my practical study of Python through exercises focused on programming fundamentals, problem solving, algorithms and increasingly complex applications.

## What I Practice

The activities in this repository cover topics such as:

- Python syntax and fundamentals;
- functions and modular code;
- strings and collections;
- dictionaries, sets and tuples;
- loops and conditional logic;
- object-oriented programming;
- recursion;
- regular expressions;
- algorithms and problem solving;
- data structures;
- error handling;
- file and data processing.

The topics evolve as I progress through the curriculum.

## Learning Format

The repository contains different types of activities from the training program, including:

- **Labs** — practical programming exercises;
- **Workshops** — guided implementations used to explore new concepts;
- **Exams** — certification and assessment projects.

Each activity is kept as an independent implementation so that the repository also serves as a record of my progress with Python.

## Running the Code

Python 3 is required.

Individual files can generally be executed directly from the repository root:

```bash
python path/to/file.py
````

For example:

```bash
python labs/example.py
```

Some activities may require specific input or follow instructions defined by the original exercise.

## Purpose

The purpose of this repository is to document my progression in Python while strengthening:

* programming fundamentals;
* algorithmic reasoning;
* problem decomposition;
* code readability;
* debugging skills;
* understanding of data structures;
* implementation of solutions from technical requirements.

Rather than representing a single application, this repository reflects continuous hands-on practice throughout the learning process.
